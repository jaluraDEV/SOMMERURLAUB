# --- E1612: G01 -- living room
E1612.0	(voice only)
E1612.1	Onkel	Nanu, um diese Zeit muht unsere Nora... // Was da wohl los ist?
E1612.2	Boku	Nora, heißt so die Kuh?
E1612.3	Onkel	Genau.
E1612.4	Boku	Warum Nora?
E1612.5	Onkel	Sie war eine streunende Kuh, eine "Nora", deshalb heißt sie Nora. // Trotzdem seltsam... ist vielleicht ein Wolf vorbeigekommen?
E1612.6	Onkel	Nora stand eines Tages plötzlich vor unserem Tor. // Und am Ende haben wir nie herausgefunden, wem sie gehört, // also wurde sie einfach die Nora unserer Familie.
# NOTE E1612.5: nora, "Streunerin"; der Onkel erklaert den Namen, daher bleibt das Wort sichtbar (Glossar § 1).

# --- E1632: G17 -- the veranda; H06 -- the garden (the stars)
E1632.0	Boku	Klappt es heute?
E1632.1	Moe	Tja, wer weiß? Hm-hm... // Aber ich glaube, der Klang trägt ein bisschen besser als früher. // Denn weißt du...
E1632.2	Boku	Denn?
E1632.3	Moe	Denn ich habe das Gefühl, mein Spiel verleiht der Luft um mich herum... // ein ganz kleines bisschen Glanz.
E1632.4	Boku	Was soll das denn heißen?
E1632.5	Moe	Was wohl... // So eine Art Edel-Landleben vielleicht?
E1632.6	Boku	Glaube ich nicht.
E1632.7	Moe	Au, wie grausam.
E1632.8	Moe	Sag mal... // ob wohl schon mal jemand... versucht hat, die Sterne zu zählen?
E1632.9	Moe	Wenn man genau hinsieht, ist selbst in der Dunkelheit zwischen den Sternen... // feiner Lichtstaub aus winzigen Körnchen... // Hast du nicht auch das Gefühl, dort steckt alles voller Sternenstaub?
E1632.10	Moe	Als ich in der Grundschule auf Klassenfahrt in Tokio war...
E1632.11	Boku	War der Himmel da selbst nachts hell?
E1632.12	Moe	Genau, genau... // Aber es heißt, wenn Astronauten vom Weltraum aus das Leuchten der Stadt entdecken, // fühlen sie sich irgendwie erleichtert.
E1632.13	Boku	Warum ist das wohl so?
E1632.14	Moe	Warum ist das wohl so?
E1632.15	Moe	Ich wäre gern Astronautin...
# NOTE E1632.14: Moe wirft Bokus Quiz-Floskel an ihn zurueck (Glossar § 3).
