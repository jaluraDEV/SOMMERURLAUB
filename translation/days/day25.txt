# --- E2514: H15 -- the climbing kiln (the firing begins)
E2514.0	Onkel	Boku-kun, du bist pünktlich gekommen, wie versprochen. // Also dann, ich mache Feuer in der Feuerkammer des Ofens.
E2514.1	Onkel	Dieser Ofen... // ist, wie du siehst, so gebaut, als würde er den Hang hinaufklettern, deshalb heißt er Hangofen. // Bei dieser Form steigt die Hitze, wenn man unten Feuer macht, von selbst den Hang hinauf, // so kann man die Temperatur im Inneren wirkungsvoll auf über tausend Grad bringen. // Deshalb ist das eine heeeiße Arbeit, auf die ich im Hochsommer nicht allzu viel Lust habe.
E2514.2	Boku	Und was machst du danach?
E2514.3	Onkel	Erst einmal lege ich eine Weile lang alle dreißig bis vierzig Minuten viel Brennholz nach. // Und ab der Morgendämmerung mache ich das allmählich schneller, und...
E2514.4	Boku	Dann bleibst du die ganze Nacht wach.
E2514.5	Onkel	Ahaha, klar doch. // Und danach, morgen am frühen Nachmittag, wenn es drinnen die angestrebten 1.200 Grad erreicht, // halte ich das etwa zwei Stunden lang tapfer durch...
E2514.6	Boku	Mhm, mhm.
E2514.7	Onkel	und gegen Abend verschließe ich diese Feuerkammer und lösche das Feuer.
E2514.8	Boku	Und dann ist es fertig?
E2514.9	Onkel	Ja! // Aber ich muss warten, bis er von selbst abkühlt, bevor ich den Ofen öffne, // also musst du bis übermorgen Abend warten, um zu sehen, was gebrannt wurde.
E2514.10	Boku	Puh... das dauert aber lange.
E2514.11	Onkel	Ich habe schon richtig Hunger bekommen.

# --- E2515: H15 -- the climbing kiln, at night (the tanka)

E2515.1	Onkel	Morgen, wenn die Sonne aufgeht, // brauche ich noch viel mehr Brennholz als jetzt, // also muss ich heute Nacht fleißig spalten...
E2515.2	Boku	Du, was bedeutet denn das Gedicht von eben?
E2515.3	Onkel	Wenn es Nacht wird, spürt man eben doch schon den Herbst... // so ungefähr wohl.
E2515.4	Onkel	Im Grillenlied / erzittert / meines Ofens / noch zarte Flamme; / möge mein Kind von ihr umarmt sein.
E2515.5	Boku	.........
# NOTE E2515.0: Onkels Tanka (5-7-5-7-7 in klassischer Grammatik) in fuenf kurzen Versen, woertlich
#   (Stilbibel § 10). "Mein Kind" kann als die Gefaesse im Ofen gelesen werden, womit er es
#   abtut (.3); gemeint ist sein verstorbener Sohn. Wiederholt in E2712.0.

# --- E2532: G17 -- the veranda (moratorium)
E2532.0	Moe	Irgendwie war es ein trauriger Sommer...
E2532.1	Boku	...?
E2532.2	Moe	(seufz)... // Vielleicht fühlt es sich traurig an, wenn es vorbei ist, weil es so schön war.
E2532.3	Boku	Gibt es denn kein nächstes Jahr?
E2532.4	Moe	Nächstes Jahr ist nächstes Jahr. Dieser Sommer ist nur dieses Jahr... // Ach, so ist das! Deshaaalb wollte ich für immer Mittelschülerin bleiben... // genau so bleiben wie in diesem Sommer... // Ach... Erwachsene nennen das ein "Moratorium"...
E2532.5	Boku	Für mich ist das alles Chinpun-Kanpun...
E2532.6	Moe	Ahaha... das klingt wie ein Pandaname.
E2532.7	Moe	Boah... ein Moratorium also...
E2532.8	Boku	Klingt wie ein Planetarium.
E2532.9	Boku	Du, ich habe tief in der Höhle etwas Seltsames aufgehoben.
E2532.10	Moe	Hä? Was mag das sein? // Dann bring es morgen Mittag in Onee-chans Zimmer.
E2532.11	Moe	Irgendwie... seit ich diesen alten Brief gelesen habe, // sind meine Sorgen vielleicht winzig klein? // ...denke ich mir, und mein Kopf ist ganz durcheinander und dreht sich im Kreis...
E2532.12	Boku	Aber wem gehört er denn?
E2532.13	Moe	Ich weiß nicht, wem, aber, hmm, wie soll ich sagen... // das muss jemand mit einem sehr warmen Herzen zurückgelassen haben...
E2532.14	Moe	Ab morgen...
E2532.15	Boku	Was?
E2532.16	Moe	Ab morgen gebe ich mir Mühe... das habe ich mir ein bisschen vorgenommen.
# NOTE E2532.4-.8: "Moratorium" war in den 1970ern das Wort fuer aufgeschobenes Erwachsenwerden;
#   Moratorium und Planetarium sind beides Lehnwoerter (Stilbibel § 8 Typ 2). Chinpun-Kanpun (Kauderwelsch)
#   klingt wie die Namen der Pandas Kang Kang und Lan Lan im Ueno-Zoo ab 1972 (Typ 3).
