# --- E0831: G15 -- the sisters' room
E0831.0	Moe	Ich liebe die Aussicht vom Südfenster dieses Zimmers. // Der Sonnenuntergang sieht aus, als würden zwischen den Wolken lila Blumen // von einer Südseeinsel aufblühen. Das ist so schön.

# --- E0832: G17 -- the veranda; H06 -- the garden
E0832.0	Moe	Hm-hm, ich bin ein kleines bisschen besser geworden, oder?
E0832.1	Boku	Meinst du?
E0832.2	Moe	Ach, so etwas sagst du also... // Du könntest ruhig ein bisschen Rücksicht nehmen. // Du bist schließlich ein Kostgänger. Lebensklugheit nennt man so etwas...
E0832.3	Boku	Aber es ist ein Instrument, das einen sanften Klang macht.
E0832.4	Moe	Ja, stimmt, oder? // Wenn man so von der Dunkelheit der Nacht umhüllt Klarinette spielt...
E0832.5	Moe	Die Schallwellen werden leise vom Wald aufgesogen, // und die Baumwipfel und Blumen... // und die schlaftrunkenen Tanuki-Babys und der Erdwespen-kun auf Brautschau... // ich habe das Gefühl, sie werden alle miteinander glücklich.
E0832.6	Boku	Das klingt irgendwie so, Onee-chan, // als wärst du die Mama von allen geworden.
E0832.7	Moe	Warum wohl?
E0832.8	Boku	Warum ist das wohl so?
E0832.9	Moe	Ach, stimmt ja, heute ist das Feuerwerksfest von Sagi-no-sato. // Von deinem Zimmer aus kann man es wahrscheinlich sehen.
# NOTE E0832.7-.8: Moes schlichtes "Warum wohl?" gegen Bokus Quiz-Tic (Glossar § 3).
